# 04 - Game Design Document (GDD)

## 1. Game Concept
- **Genre**: Casual multiplayer party game / memory-turn matching.
- **Theme**: Customizable items (Fruits, Animals, Sports, Pop culture, Custom text).
- **Core Loop**: Host configures room & chits → Friends join via code/link → Server generates 4x pool & shuffles → Players take turns flipping & matching chits → Winner crowned on podium → Rematch with same or new chits.

## 2. Audio & Visual Design
- **Visuals**: Dark glassmorphic modern theme, vibrant gradient accents, floating confetti, 3D CSS card flip animations.
- **Audio Synthesizer**: Web Audio API generated crisp sounds (Chit flip, Pop, Match success fanfare, Mismatch buzz, Victory fanfare). Zero heavy external audio asset downloads.
