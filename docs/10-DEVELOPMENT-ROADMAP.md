# 10 - Development Roadmap

## Phase 1: Core Engine & Custom Chits (Completed ✅)
- Authoritative server state machine (`ChitGameEngine.js`).
- Dynamic custom chits input with automatic 4x generation.
- Case-insensitive duplicate checking and min 4 type validation.
- Preset collections (Fruits, Animals, Sports, Objects, Movies, Friends).
- 3-step Create Game wizard & Lobby customizer modal.

## Phase 2: Social Multiplayer Polish (Completed ✅)
- 1-click Quick Room creation.
- Inline home page code joiner & URL deep linking (`/join?code=A7K9P`).
- WhatsApp & Link sharing.
- Rematch modal with "Use Same Chits" vs "Customize New Chits".

## Phase 3: Future Enhancements (Backlog 📋)
- Custom card sound recordings / voice packs.
- Private room passwords & tournament brackets.
- Extended board layout customizations (5x5, 6x6).
