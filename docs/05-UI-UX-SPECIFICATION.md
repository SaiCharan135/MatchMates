# 05 - UI/UX Specification

## 1. Design System Tokens
- **Background**: `#0F172A` (Deep Slate)
- **Glass Panel**: `rgba(30, 41, 59, 0.85)` with `backdrop-filter: blur(12px)`
- **Brand Gradient**: `linear-gradient(135deg, #FF9800 0%, #FF3D71 100%)`
- **Typography**: Display Header `Outfit`, Body `Inter`, Monospace for Room Codes.

## 2. Screen Specifications
1. **Home**: Hero banner, 1-Click Quick Room, Inline Room Code Join Bar, Secondary Navigation.
2. **Create Game Wizard**:
   - Step 1: Game Settings (Name, Avatar, Players 2-8, Mode, Rounds).
   - Step 2: Customize Your Chits (ChitCustomizer, Presets, Add/Edit/Delete, ×4 badges).
   - Step 3: Review & Create Room.
3. **Lobby**: Room code box, Copy Link & WhatsApp Share, Player List with Ready badges, Configured Chits summary pill list, Host Start/Edit button.
4. **Game Board**: Live HUD, Active Turn Banner, 3D Interactive Chit Grid, Confetti triggers, Floating Chat Drawer.
5. **Results**: Podium for top 3, Full player rankings, Play Again (Same Chits) vs Customize Chits Rematch.
