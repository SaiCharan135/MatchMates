# 01 - Product Requirement Document (PRD)

## Project: MatchMates (Custom Chit Multiplayer Game)

### 1. Executive Summary
**MatchMates** is a modern, real-time social multiplayer casual web game inspired by traditional chit games (like Chittilu). It enables 2–8 players to join private rooms and play matching games using completely customizable chit items.

### 2. Core Value Proposition
- **Limitless Custom Themes**: Hosts can input any chit names (Fruits, Animals, Sports, Cinema, Friends, Superheroes, Objects).
- **Automatic 4x Generation**: Entering a single name automatically provisions exactly **4 physical chits (×4)**.
- **Instant Room Access**: 5-character alphanumeric room codes, 1-click shareable links, and WhatsApp invites.
- **Server Authority**: 100% server-authoritative game state with anti-cheat sanitization and live synchronization.

### 3. Target Audience & Personas
- **Friends & Families**: Looking for quick, 5-minute casual games to play together on phones, tablets, or laptops.
- **College / Coworker Groups**: Customizing chit sets with friend names, inside jokes, or movie characters.

### 4. Key Functional Features
1. **Custom Chit Creator**: Add, inline edit, delete with confirmation, clear all, and duplicate name prevention.
2. **Preset Library**: 1-click shortcuts for Fruits, Animals, Sports, Vehicles, Movies, and Friends.
3. **Multiplayer Room System**: 5-character room code (`A7K9P`), real-time player lobby, host controls, ready-up status.
4. **Game Modes**:
   - **Grid Matching Mode**: Turn-based board matching with streak multipliers.
   - **Social Chit Pass Mode**: Secret 4-card hands with clockwise passing until 4 of a kind is collected.
5. **Rematch & Customization Flow**: Host can choose "Play Again (Same Chits)" or "Customize Chits for Rematch".
